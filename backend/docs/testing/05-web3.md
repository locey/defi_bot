# 05 - Web3 客户端与基础模块测试 (pkg/web3 + 基础设施)

## 模块概述

基础设施层提供配置管理、RPC 连接、数据库交互等核心能力。

### Web3 客户端 (pkg/web3)
- **Client**: 封装 go-ethereum 客户端，提供区块查询、余额查询、合约调用
- **ClientPool**: RPC 连接池，支持负载均衡和故障转移
- **Multicall**: 批量合约调用 (Multicall3)
- **QuoterV2**: Uniswap V3 报价器
- **WSClient**: WebSocket 客户端，支持区块订阅

### 其他基础模块
- **config**: YAML 配置加载与验证
- **database**: PostgreSQL 连接、迁移、种子数据
- **cache**: Redis 缓存

## 测试命令

```bash
# 测试所有基础模块
go run cmd/test-modules/main.go -module all

# 仅测试配置
go run cmd/test-modules/main.go -module config

# 仅测试 RPC
go run cmd/test-modules/main.go -module rpc

# 仅测试数据库
go run cmd/test-modules/main.go -module db
```

## 测试用例

### 1. 配置加载测试 (module=config)
- **验证**: 
  - 能否加载 `configs/config.yaml`
  - 配置内容是否完整 (chain_id, rpc_url, dex_count, token_count 等)
- **预期**: 
  - chain_id = 42161 (Arbitrum)
  - dex_count >= 4
  - token_count >= 10

### 2. RPC 连接测试 (module=rpc)
- **验证**:
  - 能否创建 Web3 Client
  - 能否获取区块号
  - Chain ID 是否匹配
  - 能否获取 ETH 余额
- **预期**:
  - 连接成功
  - 区块号 > 400,000,000 (Arbitrum 区块高度)
  - Chain ID = 42161

### 3. 数据库测试 (module=db)
- **验证**:
  - 能否连接 PostgreSQL
  - tokens 表有数据
  - exchanges 表有数据
  - trading_pairs 表有数据
- **预期**: 
  - 连接成功
  - 各表有种子数据

## 验证标准

| 检查项 | 通过条件 |
|--------|----------|
| 配置加载 | 无错误，字段完整 |
| RPC 连接 | 区块号 > 0 |
| Chain ID | = 42161 |
| 数据库连接 | 无错误 |
| 表数据 | tokens/exchanges 有记录 |
