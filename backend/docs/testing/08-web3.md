## 📋 模块概述

Web3 客户端模块提供区块链交互功能，包含以下核心组件：

| 文件 | 组件 | 功能 |
|------|------|------|
| `client.go` | Client | 基础 Web3 客户端 |
| `client_pool.go` | ClientPool | RPC 连接池 |
| `contracts.go` | ContractHelper | 合约交互工具 |
| `multicall.go` | Multicall | 批量调用 |
| `quoter_v2.go` | QuoterV2 | Uniswap V3 报价 |
| `uniswap_v2_pair.go` | V2Pair | V2 交易对交互 |
| `uniswap_v3_pool.go` | V3Pool | V3 池交互 |
| `ws_client.go` | WSClient | WebSocket 客户端 |

## 🧪 测试用例

### 1. Client 基础测试

#### 1.1 连接测试

**目的**: 验证能正确连接 RPC 节点

**测试步骤**:
```bash
go run cmd/test-modules/main.go -module web3
```

**验证点**:
- [ ] 连接成功
- [ ] Chain ID 正确
- [ ] 能获取区块号

**预期输出**:
```
✅ Web3 Client 连接成功
   RPC: https://arb1.arbitrum.io/rpc
   Chain ID: 42161
   当前区块: 123456789
```

#### 1.2 区块号获取测试

**测试步骤**:
```go
client, _ := web3.NewClient(rpcURL, chainID, timeout)
blockNum, err := client.GetBlockNumber()
```

**验证点**:
- [ ] 返回当前区块号
- [ ] 区块号 > 0
- [ ] 无错误

#### 1.3 余额查询测试

**测试步骤**:
```go
balance, err := client.GetBalance(ctx, address)
```

**验证点**:
- [ ] 返回余额（可能为 0）
- [ ] 单位为 wei

#### 1.4 Nonce 查询测试

**测试步骤**:
```go
nonce, err := client.GetNonce(ctx, address)
```

**验证点**:
- [ ] 返回当前 nonce
- [ ] 新地址返回 0

- [ ] 无效 RPC 被跳过
- [ ] 有效 RPC 被使用

### 4. QuoterV2 测试

#### 4.1 单跳报价测试

**目的**: 验证 Uniswap V3 单跳报价

**测试步骤**:
```go
result, err := client.QuoteExactInputSingle(ctx, QuoteParams{
    TokenIn:  WETH,
    TokenOut: USDC,
    AmountIn: big.NewInt(1e18), // 1 WETH
    Fee:      3000,
})
```

**验证点**:
- [ ] 返回 amountOut
- [ ] 返回 sqrtPriceX96After
- [ ] 返回 gasEstimate
- [ ] 数值合理

**预期输出**:
```
报价结果:
  输入: 1 WETH
  输出: 3245.67 USDC
  价格影响: 0.01%
  Gas 估算: 150000
```

#### 4.2 不同费率报价对比

**测试步骤**:
```go
fees := []uint32{500, 3000, 10000}
for _, fee := range fees {
    result, _ := client.QuoteExactInputSingle(ctx, QuoteParams{Fee: fee, ...})
    log.Printf("Fee %d: %s USDC", fee, result.AmountOut)
}
```

**验证点**:
- [ ] 不同费率结果不同
- [ ] 流动性高的费率结果更优
