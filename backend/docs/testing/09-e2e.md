## 🚨 常见问题

### 1. 连接失败

```
错误: dial tcp: connection refused
```

**解决**: 检查 Docker 服务是否启动

```bash
make docker-dev
docker-compose ps
```

### 2. 无套利机会

```
发现路径: 0
有效机会: 0
```

**原因**: 测试网流动性不足或价格无价差

**解决**: 
- 降低 min_profit_rate
- 使用主网数据（只读）

### 3. 交易失败

```
错误: execution reverted
```

**检查**:
- Keeper 地址是否有 backCaller 权限
- Vault 是否有足够资金
- 合约是否 paused

### 4. Gas 估算失败

```
错误: gas estimation failed
```

**原因**: 交易会 revert

**检查**:
- 路径是否有效
- 流动性是否足够
