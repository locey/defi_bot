## 2. 套利策略功能 (7 项)

### F-S01: DEX-DEX 多路径套利

| 属性 | 描述 |
|------|------|
| **功能描述** | 在不同 DEX 之间发现价差并执行多步骤套利交换 |
| **支持 DEX** | Uniswap V2, Uniswap V3, SushiSwap, Camelot |
| **路径长度** | 3-5 跳环形路径 (起点=终点) |
| **实现模块** | `internal/strategy/fast_detector.go`, `internal/strategy/path_finder.go` |
| **合约** | ArbitrageCore → SpotArbitrage → DoubleRouterIntegration |
| **状态** | ✅ 已实现 |

### F-S02: V2-V3 跨版本套利

| 属性 | 描述 |
|------|------|
| **功能描述** | 利用 Uniswap V2 和 V3 同一交易对的价差进行套利 |
| **模式** | V2→V3 (V2低买V3高卖) / V3→V2 (V3低买V2高卖) |
| **V3 费率** | 500 (0.05%), 3000 (0.3%), 10000 (1%) |
| **实现模块** | `internal/strategy/v2v3_strategy.go`, `internal/strategy/v3_math.go` |
| **合约** | UniswapV2V3Integration |
| **状态** | ✅ 已实现 |

### F-S03: CEX-DEX 套利

| 属性 | 描述 |
|------|------|
| **功能描述** | 检测 Binance 现货价格与链上 DEX 价格的差异并套利 |
| **CEX** | Binance (REST + WebSocket) |
| **DEX** | 链上所有已配置 DEX |
| **实现模块** | `internal/cexdex/detector.go`, `internal/strategy/cex_dex_strategy.go` |
| **状态** | ✅ 已实现 |

### F-S04: 闪电贷套利

| 属性 | 描述 |
|------|------|
| **功能描述** | 利用 Aave 闪电贷实现零资金套利，借入资金 → 套利 → 归还本息 |
| **平台** | Aave V2 (主用), Aave V3, dYdX, Uniswap V3 Flash Swap |
| **实现模块** | `internal/executor/executor.go` |
| **合约** | FlashLoanArbitrage → FlashLoanRouter → Aave LendingPool |
| **状态** | ✅ 已实现 |

### F-S05: 现货套利 (Vault 资金)

| 属性 | 描述 |
|------|------|
| **功能描述** | 使用金库中的自有资金执行套利，利润按比例分配 |
| **资金来源** | ArbitrageVault (90% 可用，10% 流动性储备) |
| **利润分配** | 平台 10% + 金库 90% |
| **实现模块** | `internal/executor/executor.go` |
| **合约** | ArbitrageCore → ArbitrageVault → SpotArbitrage |
| **状态** | ✅ 已实现 |

### F-S06: 蜜罐代币检测

| 属性 | 描述 |
|------|------|
| **功能描述** | 检测恶意代币（高卖出税、不可卖出、隐藏函数），过滤危险路径 |
| **检测维度** | 合约代码大小、ERC20 合规、可疑 Selector、黑名单 |
| **缓存** | 带 TTL 的结果缓存 |
| **实现模块** | `internal/strategy/honeypot_detector.go` |
| **状态** | ✅ 已实现 |

### F-S07: 交易路径优化

| 属性 | 描述 |
|------|------|
| **功能描述** | 优化套利路径的输入金额、滑点、Gas 消耗 |
| **优化维度** | 利润率、Gas 成本、滑点影响、置信度评分 |
| **实现模块** | `internal/strategy/optimizer.go`, `internal/strategy/gas_estimator.go` |
| **状态** | ✅ 已实现 |
