# 04 - 智能合约架构

> 文档版本：v1.0 | 日期：2026-02-11

---

## 1. 合约总览

智能合约层采用 Solidity 0.8.20 编写，使用 **Hardhat + Foundry** 双框架进行编译、测试和部署。合约设计遵循 **模块化、可升级、安全优先** 原则。

### 1.1 合约文件清单

| 分类 | 合约 | 升级模式 | 说明 |
|------|------|----------|------|
| **核心** | ArbitrageCore | UUPS | 套利编排器 |
| **核心** | FlashLoanArbitrage | 不可升级 | 闪电贷执行 |
| **核心** | SpotArbitrage | UUPS | 现货套利执行 |
| **核心** | ArbitrageVault | 不可升级 | ERC4626 资金金库 |
| **核心** | ConfigManage | UUPS | 全局配置管理 |
| **集成** | DoubleRouterIntegration | UUPS | 多路由交换 |
| **集成** | UniswapV2V3Integration | 不可升级 | V2/V3 跨版本套利 |
| **集成** | UniswapV2Integration | UUPS | V2 单路由交换 |
| **路由** | FlashLoanRouter | 不可升级 | 闪电贷平台路由 |

## 2. 核心合约详解

### 2.1 ArbitrageCore (核心编排器)

**继承关系：** `Initializable` → `UUPSUpgradeable` → `OwnableUpgradeable` → `ReentrancyGuardUpgradeable`

**职责：** 整个套利系统的入口点，负责协调各子模块完成套利操作。

**状态变量：**

```solidity
ISpotArbitrage public spotArbitrage;           // 现货套利合约
IFlashLoanSimpleReceiver public flashLoanArbitrage;  // 闪电贷合约
IConfigManager public configManager;            // 配置管理合约
address public spotArbImp;                      // SpotArbitrage 实现地址
address public platFormWallet;                  // 平台费用接收钱包
address public backCaller;                      // 后端调用者地址
address[] public supportAssets;                 // 支持的资产列表
bool public paused;                             // 暂停状态
mapping(address => IArbitrageVault) public vaults;  // 资产 → 金库映射
```

**核心函数：**

| 函数 | 权限 | 说明 |
|------|------|------|
| `initialize()` | 一次性 | 初始化合约，设置依赖地址 |
| `executeStrategy(ArbitrageParams)` | onlyBackCaller | **主入口** - 执行套利策略 |
| `executeFlashLoanArbitrageWithPlatform()` | public | 闪电贷套利（指定平台） |
| `addVault(asset, vault)` | onlyOwner | 添加资产金库 |
| `getVaultInfo(asset)` | view | 查询金库信息 |
| `setPaused(bool)` | onlyOwner | 暂停/恢复系统 |

**executeStrategy 流程：**

```
executeStrategy(params)
│
├── params.strategyType == OWN_FUNDS?
│   ├── YES → _executedVaultArbitrage()
│   │   ├── 从 Vault 提取资金
│   │   ├── 转给 SpotArbitrage 执行交换
│   │   ├── 计算利润
│   │   ├── 扣除平台费 (10%)
│   │   └── 利润返还 Vault
│   │
│   └── NO → _executedFlashLoanArbitrageWithPlatform()
│       ├── 编码交换参数
│       ├── 调用 FlashLoanArbitrage.executeFlashLoan()
│       ├── FlashLoanRouter 请求闪电贷
│       ├── Aave 回调 executeOperation()
│       ├── SpotArbitrage 执行交换
│       ├── 归还贷款 + 手续费
│       └── 利润转给指定接收方
```

**事件：**
```solidity
event VaultArbitrageExecuted(address asset, uint256 amount, uint256 profit);
event FlashLoanArbitrageExecuted(address asset, uint256 amount, uint256 profit);
event VaultAdd(address asset, address vault);
```

### 2.2 FlashLoanArbitrage (闪电贷执行)

**继承关系：** `ReentrancyGuard` → `Ownable` → `Pausable`

**职责：** 管理闪电贷的请求和回调，是 Aave LendingPool 的回调接收方。

**关键安全设计：**

```
                    ┌─────────────────┐
                    │  ArbitrageCore  │
                    │ (onlyBackCaller) │
                    └────────┬────────┘
                             │ executeFlashLoan()
                             ▼
                    ┌─────────────────┐
                    │FlashLoanArbitrage│
                    │(onlyArbitrageCore)│
                    └────────┬────────┘
                             │ requestFlashLoan()
                             ▼
                    ┌─────────────────┐
                    │ FlashLoanRouter │
                    │ (onlyAuthorized) │
                    └────────┬────────┘
                             │ flashLoanSimple()
                             ▼
                    ┌─────────────────┐
                    │ Aave LendingPool │
                    └────────┬────────┘
                             │ executeOperation() callback
                             ▼
                    ┌─────────────────┐
                    │FlashLoanArbitrage│
                    │(msg.sender验证)   │
                    └─────────────────┘
```

**核心函数：**

| 函数 | 权限 | 说明 |
|------|------|------|
| `executeFlashLoan()` | onlyArbitrageCore | 发起闪电贷请求 |
| `executeOperation()` | msg.sender==LendingPool | Aave 回调，执行套利逻辑 |
| `pause() / unpause()` | onlyOwner | 暂停控制 |

**executeOperation 安全验证：**
```solidity
// 验证调用者是 LendingPool，而非 Router
require(msg.sender == address(flashLoanRouter.configManage().lendingPool()));
```

**事件：**
```solidity
event FlashLoanRequested(address asset, uint256 amount, uint8 platform);
event FlashLoanExecuted(address asset, uint256 amount, uint256 profit);
event FlashLoanFailed(address asset, uint256 amount, string reason);
```

### 2.3 SpotArbitrage (现货套利执行)

**继承关系：** `ISpotArbitrage` → `Initializable` → `UUPSUpgradeable` → `OwnableUpgradeable`

**职责：** 实际执行多步骤 Token 交换操作。

**核心函数：**

```solidity
function executeSwaps(
    SwapStep[] calldata steps,    // 交换步骤列表
    address tokenIn,               // 起始代币
    uint256 amountIn,              // 起始金额
    address recipient              // 结果接收方
) external onlyAuthorizedCaller returns (uint256 finalAmount)
```

**SwapStep 结构：**
```solidity
struct SwapStep {
    address dex;        // DEX 路由地址
    address tokenIn;    // 输入代币
    address tokenOut;   // 输出代币
    uint24 fee;         // V3 费率 (V2 为 0)
    uint256 amountIn;   // 输入金额 (0 表示使用上一步输出)
}
```

**执行逻辑：**
1. 接收 Token → 验证余额
2. 按顺序执行 SwapStep[]
3. 使用对应 Integration 合约 (DoubleRouter / V2)
4. 最终余额转给 recipient (ArbitrageCore)

---

### 2.4 ArbitrageVault (资金金库)

**继承关系：** `IArbitrageVault` → `ERC20` → `ReentrancyGuard` → `Ownable`

**职责：** ERC4626 标准金库，用户存入资产获取份额，参与套利收益分配。

**核心概念：**

```
用户存款 → 铸造份额 (Share Token) → 金库资金用于套利 → 利润增加份额价值

份额价格 = 金库总资产 / 总份额供应
```

**核心函数：**

| 函数 | 说明 |
|------|------|
| `deposit(amount)` | 存入资产，获取份额 |
| `redeem(shares)` | 赎回份额，取回资产 |
| `withdraw(amount)` | 按金额赎回 |
| `getAvailableForArbitrage()` | 可用于套利的金额 (总资产的 90%) |
| `transferForArbitrage(amount)` | ArbitrageCore 提取资金 |
| `recordProfit(amount)` | 记录套利利润 |
| `recordLoss(amount)` | 记录套利亏损 |
| `previewDeposit(amount)` | 预览存款可得份额 |
| `previewRedeem(shares)` | 预览赎回可得资产 |

**费用结构：**

| 费用 | 默认值 | 来源 |
|------|--------|------|
| 存款费 | 0% | ConfigManage |
| 提现费 | 0.01% | ConfigManage |
| 绩效费 | 10% | ConfigManage |

**安全约束：**
- 保留 10% 资产不用于套利（流动性缓冲）
- 最小存款金额限制
- 最大总资产限制
- 紧急提现（仅非用户资产）

---

### 2.5 ConfigManage (全局配置)

**继承关系：** `IConfigManager` → `Initializable` → `OwnableUpgradeable` → `UUPSUpgradeable`

**职责：** 中心化管理所有合约的配置参数。

**配置项：**

```solidity
uint16 public version;                    // 版本号
uint256 private _profitShareFee;          // 平台利润分成 (bps)
uint256 public depositFee;                // 存款费 (bps)
uint256 public withdrawFee;               // 提现费 (bps)
uint256 public performanceFee;            // 绩效费 (bps)
uint256 public slippageTolerance;         // 滑点容忍度 (bps)
address public lendingPool;               // Aave LendingPool
address public uniswapV2Router;           // V2 路由
address public uniswapV3Router;           // V3 路由
address public sushiSwapRouter;           // SushiSwap 路由
address public arbitrageVault;            // 金库地址
address public uniswapV3Quoter;           // V3 报价器
```

**默认值：**
- 滑点容忍: 300 bps (3%)
- 绩效费: 1000 bps (10%)

## 3. 集成合约详解

### 3.1 DoubleRouterIntegration (多路由交换)

**功能：** 支持使用两个不同的 DEX Router 完成套利交换。

**典型场景：** 在 Uniswap V2 买入 → 在 SushiSwap 卖出

```solidity
function doubleRouterSwap(
    address router1,        // 第一个路由
    address router2,        // 第二个路由
    address[] path1,        // 第一条路径
    address[] path2,        // 第二条路径
    uint256 amountIn,       // 输入金额
    uint256 minAmountOut    // 最小输出
) external onlyAuthorized returns (uint256)
```

**利润验证：** 每步交换后验证输出 > 预期，失败则 revert

### 3.2 UniswapV2V3Integration (跨版本套利)

**功能：** 在 Uniswap V2 和 V3 之间进行跨版本套利。

**两种模式：**

```
模式1: arbitrageV2ToV3()
  Uniswap V2 买入 (较低价格) → Uniswap V3 卖出 (较高价格)

模式2: arbitrageV3ToV2()
  Uniswap V3 买入 (较低价格) → Uniswap V2 卖出 (较高价格)
```

**V3 费率支持：** 500 (0.05%), 3000 (0.3%), 10000 (1%)

**滑点计算：** 基于交易金额动态计算滑点 BPS

### 3.3 UniswapV2Integration (V2 集成)

**功能：** 封装 Uniswap V2 兼容路由的交换操作。

```solidity
function swapV2(router, path, amountIn, minAmountOut)      // 单路径交换
function swapV2Multi(router, paths[], amountIn, minAmountOut)  // 多路径交换
function routerArbCheck(router, path, amountIn)             // 盈利检查
```

## 4. 路由合约

### 4.1 FlashLoanRouter (闪电贷路由)

**功能：** 统一管理多平台闪电贷请求。

**支持平台：**

```solidity
enum LendingPlatForm {
    Aave_V2,       // Aave V2
    Aave_V3,       // Aave V3
    DYDX,          // dYdX
    UNISWAP_V3     // Uniswap V3 Flash Swap
}
```

**平台配置：**
```solidity
struct PlatFormConfig {
    address lendingPool;    // 贷款池地址
    uint16 referralCode;    // 推荐码
    uint256 maxLoanRatio;   // 最大贷款比率 (默认 50%)
}
```

## 5. 合约交互流程图

### 5.1 自有资金套利流程

```
后端 (Go)
    │ executeStrategy(params{strategyType: OWN_FUNDS})
    ▼
ArbitrageCore
    │ 验证 backCaller 权限
    │ 验证 whenNotPaused
    ▼
_executedVaultArbitrage()
    │ vault.transferForArbitrage(amount)
    ▼
ArbitrageVault
    │ 转出资金 → ArbitrageCore
    ▼
ArbitrageCore
    │ 转给 SpotArbitrage
    ▼
SpotArbitrage.executeSwaps(steps)
    │ 循环执行 SwapStep[]
    ├── Step 1: DoubleRouterIntegration.swap(router1, ...)
    ├── Step 2: DoubleRouterIntegration.swap(router2, ...)
    └── Step N: ...
    │ 结果返回 ArbitrageCore
    ▼
ArbitrageCore
    │ 计算利润 = 输出 - 输入
    │ 平台费 = 利润 * 10%
    │ vault.recordProfit(利润 - 平台费)
    └── emit VaultArbitrageExecuted
```

### 5.2 闪电贷套利流程

```
后端 (Go)
    │ executeFlashLoanArbitrageWithPlatform(asset, amount, platform, swapParams)
    ▼
ArbitrageCore
    ▼
FlashLoanArbitrage.executeFlashLoan()
    ▼
FlashLoanRouter.requestFlashLoan()
    ▼
Aave LendingPool.flashLoanSimple()
    │ 转入借贷资产
    ▼
FlashLoanArbitrage.executeOperation()  ← Aave 回调
    │ 验证 msg.sender == LendingPool
    │ 将资金转给 SpotArbitrage
    ▼
SpotArbitrage.executeSwaps(steps)
    │ 执行多步交换
    ▼
FlashLoanArbitrage
    │ approve(LendingPool, 本金 + 手续费)
    │ 利润 = 余额 - 本金 - 手续费
    │ 转利润给接收方
    └── emit FlashLoanExecuted
```

## 8. 安全特性总结

| 特性 | 合约 | 说明 |
|------|------|------|
| UUPS 可升级 | Core, Spot, Config, DoubleRouter | 可安全升级逻辑 |
| 重入防护 | 所有核心合约 | ReentrancyGuard |
| 多层权限 | 所有合约 | onlyOwner / onlyBackCaller / onlyAuthorized |
| 暂停机制 | Core, FlashLoan, Vault | 紧急暂停开关 |
| 利润验证 | Core, Integrations | minProfit / minAmountOut 检查 |
| 滑点保护 | Integrations | 动态滑点 BPS 计算 |
| LendingPool 验证 | FlashLoanArbitrage | 验证回调 msg.sender |
| 紧急提现 | Vault | 仅限非用户资金 |
