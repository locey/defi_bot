## 2. 数据流架构

### 2.1 核心数据流

```
数据源 (DEX/CEX/链上)
    │
    ▼
┌─────────────────────┐
│    Collector Layer   │  ← 并发采集 (20+ goroutines)
│  • DEX 价格采集      │
│  • CEX Ticker 采集   │
│  • Gas 价格采集      │
│  • 区块订阅          │
│  • 新池监听          │
└─────────┬───────────┘
          │ 价格数据 / 事件
          ▼
┌─────────────────────┐
│    Redis Cache       │  ← 高频价格缓存
│  • 价格缓存 (TTL)    │
│  • 订单簿缓存        │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│   Strategy Engine    │  ← 策略分析
│  • 路径发现          │
│  • 利润计算          │
│  • 蜜罐过滤          │
│  • 机会评分          │
└─────────┬───────────┘
          │ ArbitrageOpportunity
          ▼
┌─────────────────────┐
│   Executor Engine    │  ← 交易执行
│  1. 模拟验证         │
│  2. Gas 估算         │
│  3. 构建交易         │
│  4. 发送交易         │
│  5. 等待确认         │
└─────────┬───────────┘
          │ ExecutionResult
          ▼
┌─────────────────────┐
│  Persistence Layer   │
│  • PostgreSQL 存储   │
│  • 异步批量写入      │
└─────────────────────┘
```

### 2.2 事件驱动流 (高性能模式)

```
链上事件 (Swap/Sync/PoolCreated)
    │
    ▼
Block Subscriber ──→ 新区块通知
    │
    ▼
Pool Watcher ──→ 新池事件 → Token 过滤 → 路径更新
    │
    ▼
Fast Detector
    │  监听价格变化
    │  仅重新计算受影响的路径
    │  增量更新，非全量扫描
    ▼
Opportunity Channel ──→ Executor ──→ 链上执行
```

## 5. 安全架构

### 5.1 链上安全

| 机制 | 说明 |
|------|------|
| **UUPS 可升级** | ArbitrageCore, SpotArbitrage, ConfigManage 支持升级 |
| **重入防护** | ReentrancyGuard 保护所有关键函数 |
| **访问控制** | onlyOwner, onlyBackCaller, onlyAuthorized 多层权限 |
| **暂停机制** | Pausable 模式，紧急情况可暂停 |
| **利润验证** | minProfit 检查，防止亏损交易 |
| **滑点保护** | 动态滑点计算，最小输出量验证 |

### 5.2 链下安全

| 机制 | 说明 |
|------|------|
| **交易模拟** | 执行前通过 eth_call 模拟 |
| **蜜罐检测** | 合约代码分析 + 黑名单机制 |
| **私有交易** | Flashbots Protect 防 MEV 抢跑 |
| **Gas 缓冲** | Gas 估算 +20% 安全缓冲 |
| **Nonce 管理** | 防止 Nonce 冲突 |
| **速率限制** | API 速率限制 + CEX 请求限流 |

## 6. 性能优化设计

| 优化策略 | 实现方式 |
|----------|----------|
| **RPC 连接池** | 多节点负载均衡，避免单点瓶颈 |
| **并发采集** | 20+ goroutines 并发数据采集 |
| **Redis 缓存** | 价格数据 TTL 缓存，减少 RPC 调用 |
| **增量检测** | Fast Detector 仅检测价格变化影响的路径 |
| **异步写入** | 批量异步数据库写入（50 条/批或 5 秒刷新） |
| **WebSocket** | 实时价格推送，低延迟 |
| **EIP-1559** | 支持 EIP-1559 交易类型，fallback legacy |
| **路径预计算** | 启动时预计算所有套利路径 |
| **Multicall** | 批量链上查询，减少 RPC 次数 |
