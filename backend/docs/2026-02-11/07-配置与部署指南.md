## 1. 环境要求

### 1.1 基础环境

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Go | 1.21+ | 后端编译 |
| PostgreSQL | 15+ | 主数据库 |
| Redis | 7+ | 缓存层 |
| Node.js | 18+ | 前端 + 合约编译 |
| Docker | 20.10+ | 容器化部署 |
| Docker Compose | 2.0+ | 多容器编排 |

### 1.2 区块链环境

| 组件 | 说明 |
|------|------|
| RPC 节点 | Alchemy / Infura / 自建节点 |
| WebSocket 节点 | 实时事件订阅 |
| 签名私钥 | Keeper 账户 (执行交易) |
| Etherscan API Key | 合约验证 (可选) |

## 3. 环境变量

| 变量 | 说明 | 必须 |
|------|------|------|
| `KEEPER_PRIVATE_KEY` | 交易签名私钥 | ✅ |
| `BINANCE_API_KEY` | Binance API Key | CEX-DEX 时需要 |
| `BINANCE_API_SECRET` | Binance API Secret | CEX-DEX 时需要 |
| `TELEGRAM_BOT_TOKEN` | Telegram Bot Token | 通知时需要 |
| `TELEGRAM_CHAT_ID` | Telegram Chat ID | 通知时需要 |
| `DATABASE_URL` | 数据库 URL (覆盖 YAML) | 可选 |
| `REDIS_URL` | Redis URL (覆盖 YAML) | 可选 |

## 4. 构建与运行

### 4.1 Makefile 命令

```bash
# 编译
make build                    # 编译服务端二进制

# 运行
make run                      # 运行服务 (使用 config.yaml)

# Docker
make docker-up                # 启动 Docker 服务 (生产)
make docker-dev               # 启动 Docker 服务 (开发)

# 数据库
make migrate                  # 执行数据库迁移
make seed                     # 填充种子数据

# 合约
make generate-bindings        # 生成 Go 合约绑定
```

### 4.2 本地开发

```bash
# 1. 启动基础服务
docker-compose -f docker-compose.dev.yml up -d postgres redis

# 2. 配置环境变量
export KEEPER_PRIVATE_KEY=0x...
export BINANCE_API_KEY=...
export BINANCE_API_SECRET=...

# 3. 编译并运行
cd backend
go build -o bin/server ./cmd/server
./bin/server --config configs/config.yaml
```

### 4.3 Docker 部署

```bash
# 构建镜像
docker build -t defi-bot-backend .

# 启动全部服务
docker-compose up -d

# 查看日志
docker-compose logs -f defi-bot-backend
```

## 5. Docker Compose 配置

### 5.1 生产环境 (docker-compose.yml)

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:15
    environment:
      POSTGRES_DB: defi_arbitrage
      POSTGRES_USER: defi_bot
      POSTGRES_PASSWORD: secure_password
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  defi-bot-backend:
    build: .
    depends_on:
      - postgres
      - redis
    ports:
      - "8080:8080"
      - "9090:9090"       # Prometheus metrics
    environment:
      - KEEPER_PRIVATE_KEY=${KEEPER_PRIVATE_KEY}
    volumes:
      - ./configs:/app/configs

volumes:
  pgdata:
```

### 5.2 开发环境 (docker-compose.dev.yml)

开发环境仅启动基础设施 (PostgreSQL + Redis)，后端本地运行便于调试。

## 7. 监控与运维

### 7.1 健康检查

```bash
# API 健康检查
curl http://localhost:8080/health

# Prometheus 指标
curl http://localhost:9090/metrics
```

### 7.2 日志

- 日志格式: JSON (zerolog)
- 日志级别: debug / info / warn / error
- 关键日志:
  - 套利机会发现
  - 交易执行结果
  - 错误和异常

### 7.3 常见问题排查

| 问题 | 排查步骤 |
|------|----------|
| RPC 连接失败 | 检查 RPC URL、网络连通性、API Key 有效性 |
| 交易失败 | 查看链上 revert 原因、检查 Gas 设置 |
| 数据库连接失败 | 检查 PostgreSQL 状态、连接参数 |
| Redis 连接失败 | 检查 Redis 状态、端口 |
| 利润计算异常 | 检查价格数据时效性、精度问题 |
| 蜜罐误判 | 检查黑名单、调整检测阈值 |

## 8. 安全注意事项

| 项目 | 建议 |
|------|------|
| 私钥管理 | 使用环境变量或密钥管理服务，绝不硬编码 |
| RPC 端点 | 使用付费节点，避免公共节点的速率限制 |
| 数据库 | 启用 SSL，使用强密码，限制网络访问 |
| API | 生产环境启用认证，限制公网暴露 |
| 合约升级 | 使用多签钱包管理 Owner 权限 |
| 监控告警 | 设置异常交易、余额告警 |
