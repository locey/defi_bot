## 二、MEV 策略详细分析

### A1. 三明治攻击 (Sandwich Attack)

**机制：** 监控 mempool 中的大额 swap，在目标交易前插入买单（frontrun），在目标交易后插入卖单（backrun）。

- **资本需求：** 5-50 ETH
- **基础设施：** Ethereum 主网需要 Flashbots Builder API；L2 上基本不可行（Arbitrum/Base/OP 使用中心化 Sequencer，无公开 mempool）
- **预期利润：** 单笔 $5-$500，日均 $1K-$50K（顶级团队）
- **竞争程度：** 极高。以太坊主网被 ~20 个顶级 Searcher 垄断
- **对本项目适用性：** **不推荐。** Arbitrum/Base 无 mempool，以太坊主网竞争过于激烈。且存在声誉风险。

### A2. 反向跟单 (Backrunning)

**机制：** 在大额交易之后立即提交交易，捕获被打破的价格平衡。不伤害原始交易者，是"善意 MEV"。

- **资本需求：** 1-10 ETH
- **预期利润：** 单笔 $1-$100，月利 $500-$10K
- **竞争程度：** 中高
- **对本项目适用性：** **可行，优先级中。** 已有鲸鱼检测（SwapEvent >1 ETH → SpreadScanner.ScanNow()），需要将延迟压缩到 <500ms。

### A3. JIT (Just-In-Time) 流动性

**机制：** 在大额 swap 前向对应 tick 范围注入集中流动性，赚取手续费后立即撤出。

- **资本需求：** 10-100 ETH
- **竞争程度：** 高
- **对本项目适用性：** **不推荐。** 需要 mempool 访问 + 极低延迟 + 大量资本。Arbitrum 上无法实现。

### A4. 清算机器人 (Liquidation Bot) ⭐️

**机制：** 监控 Aave V3、Compound V3 等借贷协议的不健康仓位（health factor < 1），执行清算获得清算奖励（5-10%）。

- **资本需求：** 闪电贷 = 近乎 0（本项目已有 Aave V3 FlashLoan 集成！）
- **预期利润：** 日均 $100-$2,000（大跌行情中可能 $10K+）
- **竞争程度：** 中。不像 DEX 套利那样被完全覆盖
- **实现难度：** 中
- **对本项目适用性：** **强烈推荐，优先级最高。** 原因：
  - 已有 FlashLoanArbitrage 合约（0x8dbc...），稍作修改即可支持清算
  - 已有 Aave V3 LendingPool 地址
  - 已有 Multicall 批量查询能力
  - Arbitrum 上 Aave V3 TVL ~$2B，清算事件频繁
  - 闪电贷清算 = 0 资本需求

### A5. NFT Sniping

**对本项目适用性：** **不推荐。** 与现有代码库完全不相关，需要全新开发。

## 三、套利变体分析

### B1. 跨链套利 (Cross-Chain Arbitrage)

**机制：** 同一代币在不同链上价格不同时，通过桥转移套利。

- **资本需求：** 5-50 ETH
- **风险：** 高。桥接延迟不可控（5-15min），非原子性
- **对本项目适用性：** **可选，优先级低。** 风险太高且非原子。

### B2. 同链原子跨 DEX 套利

**现状：** 在 Arbitrum 上 91 次尝试 0 盈利（公共 RPC 3-8s）。

**可改善方向：**
1. 长尾代币池（TVL < $100K 竞争少）
2. 新链/新 DEX 上线初期
3. 极端行情中价差可达 1-5%
4. **专用 RPC 是关键** — 延迟从 3-8s → <200ms 可能激活被杀死的机会

### B3. 稳定币脱锚套利

**机制：** 当 USDC/USDT/DAI 偏离 $1.00 时买入/卖出。

- **预期利润：** 正常市场 ~0。脱锚事件中 $1K-$100K+
- **对本项目适用性：** **推荐作为被动监控策略。** 低成本实现，设置偏差告警。

### B4. Wrapped Token 套利 (wstETH/stETH, cbETH/ETH)

**对本项目适用性：** **不推荐。** 利差太小 (<0.01%)，竞争太高。

## 十、结论

**最终建议的优先级：**

```
RPC 升级 ($49/月) > 清算机器人 > Base 部署 > UniswapX Solver > CEX API > 新 L2
```

当前瓶颈不是代码质量，而是：
1. **延迟** — $49/月 Alchemy 是 ROI 最高的单一改动
2. **策略单一** — 清算机器人是复用现有代码最多、竞争较低的下一策略
3. **单链局限** — Base 已检测到 0.2-0.7% CEX-DEX 价差
4. **市场选择** — 长尾池、新链、清算、Intent Solver 仍有空间
